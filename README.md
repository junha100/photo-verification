# 사진 검증 프로그램

중고거래 사진의 AI 생성 가능성, 생성·편집 기록, 상품 사진 간 일관성을 확인하는 수업 프로젝트입니다.

- AI 판별: 로컬 DDA와 추가 학습한 판정부. 고정 평가 400장 중 303장 정답이며 실제 서비스 전체 정확도를 의미하지 않습니다.
- 출처 확인: 파일에 남아 있는 생성·편집 기록과 C2PA 정보를 확인합니다. 기록이 없다는 이유로 실제 사진이라고 판단하지 않습니다.
- 상품 사진 비교: Groq 이미지 모델로 2~3장을 비교합니다. 같은 실물이나 정품임을 보증하지 않습니다.
- 히트맵: 별도 CLIP 기반 보조 자료입니다. DDA의 직접적인 Grad-CAM이 아닙니다.

## 설치와 실행

1. Windows 10/11 64비트, Python 3.12, Node.js 22.12 이상을 설치합니다.
2. 저장소를 복제하거나 ZIP으로 받아 압축을 해제합니다.
3. Git Credential Manager로 저장소 접근 권한이 있는 GitHub 계정에 로그인합니다. 모델 다운로드에 필요합니다.
4. `설치.cmd`를 실행합니다. 필요한 모델 약 3.7GB를 비공개 릴리스에서 받아 크기와 SHA-256을 검증하고 실행 환경을 설치합니다.
5. `실행.cmd`를 실행하고 http://127.0.0.1:5174 에 접속합니다. 종료할 때 `종료.cmd`를 실행합니다.

자동 다운로드가 어려우면 릴리스의 모델 5개를 직접 받고 `model-manifest.json`의 asset → path에 맞게 배치한 다음 설치하세요.

## 공유 설정

사용자 요청에 따라 이 **비공개 팀 저장소의 루트 .env에는 공유 Groq API 키가 포함**됩니다. 공유 키의 무료 사용 한도를 팀원이 함께 소모합니다. GitHub 로그인 토큰, 개인 분석 기록, DB, 테스트 사진, 캐시, 설치된 실행 환경은 포함하지 않습니다. 공개 저장소로 변경하거나 외부에 재배포하기 전 공유 키를 제거하고 교체해야 합니다.

기존 전체 실행용 압축본과 달리 모델은 릴리스에 분리 보관합니다. 모델을 제외한 코드만 복제해도 설치 과정에서 모델을 받을 수 있습니다. 학습 데이터와 재학습 환경은 포함하지 않습니다.

현재 프로그램의 한계와 세부 실행 방법은 `README_실행방법.txt`를 참고하세요.
