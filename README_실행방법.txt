사진 검증 프로그램 — 팀원 공유본

[포함 기능]
사진 AI 판별(DDA + 추가 학습 판정부), 출처·생성·편집 기록 확인,
상품 사진 2~3장 비교, 보조 히트맵과 결과 설명.
정품·동일한 실물·거래 안전을 보증하지 않습니다.

[준비]
Windows 10/11 64비트, Python 3.12 64비트, Node.js 22.12 이상(LTS).
Python 3.13 이상은 현재 코드의 cgi 모듈과 호환되지 않습니다.
RAM 16GB 이상 권장. 설치 시 인터넷과 추가 디스크 공간이 필요합니다.

[실행 순서]
1. 압축 파일 안에서 실행하지 말고 폴더 전체를 먼저 압축 해제합니다.
2. 처음 한 번 설치.cmd를 실행합니다. Python·웹 라이브러리를 내려받습니다.
3. 실행.cmd를 실행합니다. http://127.0.0.1:5174 가 열립니다.
4. 사용을 끝내면 종료.cmd를 실행합니다.

[API 설정]
팀원 전용 전체 압축본에는 요청에 따라 공유 Groq 키가 포함됩니다.
이 비공개 GitHub 저장소에는 공유 키가 포함되며 모델은 릴리스에서 받습니다.
공개 GitHub에는 키가 포함된 전체 압축본이나 .env를 올리지 마세요.
Groq Free 플랜 사용 한도는 키를 공유하는 팀원들이 함께 소모합니다.
계정이 유료 플랜이면 해당 계정의 요금 정책이 적용됩니다.
키는 폴더 루트 .env의 GROQ_API_KEY에서 교체할 수 있습니다.
설명은 gpt-oss-20b, 상품 사진 비교는 Qwen 이미지 모델을 Groq에서 사용합니다.
AI 판별은 로컬 PC에서 실행합니다. 키가 없어도 AI 판별은 가능하지만,
상품 사진 비교에는 정상적인 Groq 키가 필요하고 설명은 기본 문구로 대체됩니다.

[공유 구성]
전체 실행용: 코드 + 필요한 모델 5개(큰 모델 4개와 작은 추가 학습 판정부) + 공유 키.
비공개 GitHub 공유본: 코드 + 공유 키 + 모델 자동 다운로드 기능.
설치.cmd가 비공개 릴리스의 모델을 다운로드합니다. 저장소 접근 권한과 GitHub 로그인이 필요합니다.
기존 .venv/node_modules, 학습·테스트 사진, 개인 분석 기록, DB, 로그,
캐시, Git 이력, 사용하지 않는 영상·텍스트·확장 프로그램·관리자 화면은 제외했습니다.
모델 재학습용 패키지가 아니라 현재 사진 서비스 실행용 패키지입니다.

[현재 판별 성능의 범위]
고정 평가 400장에서 추가 학습 전 269장, 추가 학습 후 303장 정답.
AI 200장 중 117장 탐지, 일반 사진 200장 중 14장 오탐.
실제 서비스 전체 정확도나 Hive와의 비교 결과는 아닙니다.
히트맵은 별도 CLIP 기반 보조 자료이며 DDA의 직접적인 Grad-CAM이 아닙니다.

[문제가 있으면]
모델 누락: GitHub 로그인 후 설치.cmd를 다시 실행하거나 릴리스에서 직접 받습니다.
설치 실패: Python 3.12와 Node.js 버전, 인터넷 연결을 확인합니다.
실행 실패: .local 폴더의 inference.err.log, gateway.err.log, web.err.log를 확인합니다.
서버 포트 5174, 8001, 8787을 다른 프로그램이 사용하면 먼저 정리합니다.

[검증 범위]
공유본의 모델 무결성, Python 모듈과 판별 결과, 웹 빌드는 확인합니다.
팀원 PC의 운영체제·설치 권한·네트워크 환경까지 직접 확인한 것은 아닙니다.

[화면 설정 정리]
얼굴 선택·얼굴 가중치를 제거했습니다. 빠른·정밀은 DDA 최종 점수가 같고 히트맵 계산 범위만 다릅니다.
개발자 모드와 결과·점수를 강제로 바꾸는 코드도 제거했으며 실제 분석 결과를 그대로 표시합니다.
